# Control de finanzas personales

## Problema

Este proyecto nace porque necesito comparar mis ahorros mensuales con un objetivo financiero. La información entregada por el banco permite revisar movimientos individuales, pero no facilita visualizar de forma simple si los ingresos, gastos y ahorros de cada mes son consistentes con una meta de ahorro definida.

## Solución

La solución consiste en un flujo automatizado que transforma cartolas bancarias en indicadores de ahorro mensual y los compara con un objetivo financiero. Para ello, las transacciones son procesadas, clasificadas y consolidadas para generar visualizaciones que facilitan el análisis de los resultados mes a mes.

## Proceso

Para lograr este objetivo, recopilé los datos desde el banco, limpié y unifiqué los montos, clasifiqué los gastos por categoría y generé visualizaciones para facilitar el análisis.

## Características

* Clasificación automática de transacciones mediante palabras clave.
* Diccionario configurable directamente desde Google Sheets.
* Manejo de transacciones desconocidas mediante la categoría "Otros".
* Identificación de ingresos y gastos.
* Consolidación de movimientos por período.
* Cálculo de ahorro mensual.
* Comparación entre ahorro real y objetivo financiero.
* Automatización desarrollada con Google Apps Script.

## Resultado

Gracias a esta solución, ahora puedo monitorear el comportamiento de mis ahorros mes a mes, compararlos con un objetivo financiero y evaluar de forma más clara el impacto de mis gastos e ingresos sobre mi capacidad de ahorro.
